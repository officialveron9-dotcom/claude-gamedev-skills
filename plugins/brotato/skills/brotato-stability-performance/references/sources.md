## Not verified

- Whether the shipped Brotato build is a debug or release export (affects whether runtime `SCRIPT ERROR`s
  are printed and abort functions, whether signature mismatches are parse errors, whether `assert()` fires and
  whether CLI debug flags work). Evidence conflicts: the F2 debug menu is gated on `OS.is_debug_build()` (points to
  release), player-log snippets show runtime `SCRIPT ERROR`s (points to debug-enabled).
- The engine build of the newest Brotato (1.1.15.x): no 1.1.15 log was found here; `3.7.dev` comes from the
  `brotato-modding` sibling skill. Nothing in this skill depends on 3.6/3.7-only APIs.
- Performance budgets (≤ 1 ms average) and network intervals are guidance and one mod's values, not official limits.

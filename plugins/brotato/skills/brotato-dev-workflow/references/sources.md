## Inferred (not directly observed)

- `_custom_features = ""` switching the game to its local platform and Mod Loader to the default (non-Workshop) profile: **[infer]** from FullMapCamera's working test packs (zips loaded from `<exe dir>/mods/` after that patch) and Combat Tracker's explicit `options.tres` replacement; Brotato's shipped `options.tres` was not read.
- `res://mods-unpacked/` beside `Brotato.exe` being invisible: **[infer]** from Mod Loader enumerating `res://mods-unpacked/` with `Directory` and Godot 3 serving `res://` from the PCK in exported games; all reference mods test the exe with zips or pack overlays, never with a loose folder.
- pre-commit needing `additional_dependencies: ["setuptools<81"]`: **[infer]** from the venv observation; pre-commit builds the hook in its own venv.
- `--time-scale` speeding up Brotato: engine flag verified, effect on the game not measured.
- Brotato's CrashReporter condition (`ERROR`/`SCRIPT ERROR` mentioning `mods-unpacked`): from `brotato-stability-performance` and mojimoon's runner comment, not from game source.

# Tools und SDKs: Unreal Engine 5.8, FiveM, Brotato, allgemein

Stand: **2026-10-08**. Praktische Übersicht, was gegen Lag, Abstürze, Desync und langsames Arbeiten hilft und
wie man es anschließt. Keine Werbung, keine Vollständigkeit.

**So wurde geprüft:**
- Claude-Code-Mechanik: Doku auf code.claude.com/docs (`hooks`, `hooks-guide`, `settings`, `permissions`, `memory`, `mcp`, `plugins/code-intelligence`, `cloud-environments`) am 2026-10-08 gelesen.
- Werkzeuge: Quell-Repos geklont oder Tags per `git ls-remote` gelesen (Versionsnummern unten stammen daher); `gdtoolkit 3.6.0` und `luacheck 1.1.2` wurden in der Sandbox installiert und mit den Vorlagen aus `templates/` ausgeführt.
- Herstellerseiten (dev.epicgames.com, docs.fivem.net, luals.github.io, forums.unrealengine.com) sind aus der Sandbox gesperrt; solche Angaben sind über den Suchindex belegt und mit **(Suchindex)** markiert. Nicht belegte Angaben stehen als **(ungeprüft)**.
- Spalte „Claude Code“: **web** = Cloud-Session (claude.ai/code, Ubuntu-VM), **lokal** = Terminal, Desktop-App oder VS Code auf deinem PC, **beide**. Ein Werkzeug, das einen laufenden Editor, das Spiel oder eine GPU braucht, ist immer nur lokal.

## 5. Kurzfassung: Was zuerst installieren

1. **Alle Projekte:** Git for Windows, jq, Python + pipx, Vorlagen aus `templates/` kopieren, Skills nach `.claude/skills/`.
2. **Unreal:** `clangd-lsp` + LLVM, `compile_commands.json` erzeugen, `.mcp.json` mit `unreal-api` (und Epics Plugin, sobald Editor-Aufgaben anstehen). Für Lag: Unreal Insights, dann RenderDoc. Für Release: Sentry, DLSS/FSR.
3. **FiveM:** `lua-lsp` + lua-language-server + fivem-lls-addon, luacheck, Artifacts aktuell halten, txAdmin; für Enhanced Alchemist.
4. **Brotato:** gdtoolkit 3.x (mit `setuptools<80`), Godot 3.6 Editor, GDRE Tools; clumsy vor Online-Tests.
